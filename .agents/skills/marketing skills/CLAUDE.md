## How to use

Pick a skill based on what you're working on:
- Writing an email? Use `/cold-email`
- Building a prospect list? Use `/prospecting`
- Want better conversion rates? Use `/cro` or `/ab-testing`
- Need positioning? Use `/product-marketing`
- Analyzing performance? Use `/analytics`

Each skill is self-contained with references, frameworks, and benchmarks. They cross-link — e.g., cold-email links to prospecting as its upstream step.
